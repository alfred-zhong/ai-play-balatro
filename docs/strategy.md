# Balatro 通关攻略（给定模式、白注、黑色牌组）

来源：SteelSeries 小丑牌评级 + Balatro University 高分思路 + 实战观察。
用途：AI 打牌时的决策参考，不是硬性规则。

---

## 一、最重要的一条：必须建立 ×倍率（xmult）引擎

底注 4 之后门槛是 10000 / 20000 分级别，**纯 +倍率（+mult）和加筹码（+chips）一定不够**。

计分是 `(筹码) × (倍率)`。+倍率是线性叠加，×倍率是乘上去：

- 3 张 +10 倍率的牌 → 倍率 30，配 100 筹码 = 3000 分
- 1 张 ×3 倍率 + 1 张 ×2 倍率 → 倍率 ×6，配 100 筹码 = 600 分，但如果基础倍率是 10 → 10×6=60，配 100 筹码 = 6000 分

**前期可以靠 +倍率过活，底注 4 开始必须至少有一张 ×倍率牌，底注 6 之后需要两三张。**

### 优先抢的 ×倍率小丑牌（见到就买，除非完全没钱）

| 小丑 | 效果 | 说明 |
|---|---|---|
| Blueprint | 复制右侧小丑牌效果 | S 级，见到必买 |
| Brainstorm | 复制最左侧小丑牌效果 | S 级 |
| Cavendish | 无条件 ×3 倍率 | 顶级中奖牌 |
| Triboulet | 每张 K/Q/J ×2 倍率 | 传奇牌 |
| Baron | 每张 K ×1.5 倍率（在手牌中） | 见下「手牌保留」用法 |
| Photograph | 打出的第一张计分牌 ×2 | 配人头牌极强 |
| Hologram | 每加一张牌 ×+0.25 | 成长型，越早买越好 |
| Constellation | 每用一个星球牌 ×+0.1 | 配星球牌流 |
| Campfire | 每卖一张牌 ×+0.5 | 需要频繁卖牌 |
| Obelisk | 连续不重复牌型 ×+1 | 后期强 |
| Bloodstone | 每张红桃 50% 概率 ×1.5 | 红桃流 |
| Ancient | 每张指定花色 ×1.5 | 同色流 |

### 当前这局的诊断
`Sock and Buskin + Hiker + Golden + Even Steven + Greedy + Crazy` 这套组合里
**没有一张 ×倍率牌**，全是加筹码/加倍率/给钱。这意味着底注 5-6 会打不动。
→ 除非很快抢到 ×倍率牌，否则这局上限在底注 5 左右。

## 二、牌型专精：锁定 1-2 个牌型，疯狂升级

不要什么都玩。选一个好成的牌型，用星球牌把它升级到 Lv5 以上：

- **Pair / Two Pair**：最好成，升级快，配 The Duo（×2）或 Spare Trousers
- **Flush**：黑色牌组没有花色优势，但两张花色够多时好用，配 The Tribe（×2）
- **Straight**：配 The Order（×3），但难成
- **High Card**：后期流派，需要特定小丑牌（如 Baron + 手牌保留）

**星球牌永远当回合就用掉**，不要囤。每级都给底分和倍率，永久生效。

## 三、经济管理（这是很多人死掉的真原因）

- 每回合结束**剩 $1 就有 $1 利息，上限 $5**。所以手上有 $25 以上时，利息吃满。
- 前期（底注 1-2）：尽量攒到 $25 吃满利息，但**看到 ×倍率牌或关键牌要舍得花钱**。
- 后期（底注 6+）：钱的意义下降，**有钱就花在能立刻提升战斗力上**。
- 不要为了利息错过能翻倍的牌。宁可 $0 有 ×3 倍率，也别 $25 只有 +倍率。

### 值得买的经济牌
Golden Joker（每回合 +$4）、To the Moon（每回合额外利息）、Mail-In Rebate、Rocket。

## 四、Boss 盲注必须读效果再决定

`mech.py look` 的 `blind[boss] effect` 字段会写明限制。常见坑：

| Boss | 效果 | 应对 |
|---|---|---|
| The Psychic | 必须出 5 张牌 | 无论如何凑满 5 张 |
| The Goad / The Club 等 | 某花色全部被削弱（debuff） | 避开该花色，`look` 的分数已算入 |
| The Wall | 极高分数门槛 | 别留弃牌，全力输出 |
| The Water | 弃牌次数变 0 | 前面别浪费弃牌 |
| The Pillar | 本底注用过的牌被削弱 | 轮换用牌 |
| The Wheel | 抽牌可能背面朝上 | 靠运气，做好最坏打算 |
| The Head | 人头牌被削弱 | 避开头牌 |
| The Flint | 基础牌型分减半 | 需要更强的小丑牌 |
| The Ox | 打出的牌型归零重来 | 换牌型 |
| Cerulean Bell | 强制选 1 张牌 | 无法选 5 张，靠单张牌强度 |

**用 Luchador（卖掉可禁用 Boss 效果）或 Chicot 可以硬解 Boss。**

## 五、弃牌是最重要的技术

1. **弃牌要弃满**。上限通常是 5 张，弃 2 张就是浪费。
2. **判断该不该弃**：`剩余手数 × 当前最高分 < 还差分` → 必须弃牌找更好的。
   反之如果够分了就直接打，别浪费弃牌次数。
3. **弃什么**：
   - 保留：成对的牌、同花色多的牌、能连成顺子的牌
   - 丢掉：孤张高牌（除非是 High Card 流派）、与其他牌完全不搭的
4. **注意**：某些小丑牌会因为弃牌而变弱（Green Joker 弃牌 -1 倍率），
   `look` 里能看到当前值，留意别把正在成长的小丑牌搞废。

## 六、手牌保留类小丑牌（容易忽略的流派）

有些小丑牌的效果作用于**手里没打出的牌**：

- **Baron**：手里每张 K 给 ×1.5 倍率
- **Shoot the Moon**：手里每张 Q 给 +13 倍率
- **Raised Fist**：手里最低的牌翻倍加到倍率

配 Baron 时，**打出的牌越少越好**（比如只打 1 张高牌），让更多 K 留在手里吃加成。
这种流派和「打满 5 张」完全相反，`look` 的精确算分会自动帮你选对。

## 七、消耗品（塔罗/星球/幽灵）

| 类型 | 用法 |
|---|---|
| 星球牌 c_*（pluto/mercury/...） | **见到就用**，升级牌型永久生效 |
| 塔罗：The Hanged Man | 摧毁 2 张牌，精简牌组（只留有用的牌） |
| 塔罗：Death | 把一张牌变成另一张的复制 → 造 4 条/同花顺 |
| 塔罗：Strength | 两张牌点数 +1 |
| 塔罗：The Sun/Moon/Star/World | 转换花色，凑同花 |
| 塔罗：Hermit | 钱翻倍（上限 +$20） |
| 塔罗：Temperance | 给钱（按小丑牌售价） |
| 幽灵：Ankh | 复制一张小丑牌 |
| 幽灵：Deja Vu / Talisman | 加封印/增强 |

**消耗品槽满了是纯浪费。要么用掉，要么别买。**

## 八、小丑牌槽位与顺序

- 计分是**从左到右**结算的。+倍率牌放左边，×倍率牌放右边（先加后乘，数值更大）。
- 例：+10 倍率在左，×2 在右 → (基础+10)×2；反过来 → 基础×2+10，后者更小。
- `rearrange` 端点可以调整顺序（mech.py 目前没暴露，需要时提出来加）。

## 九、不同底注的心理预期

| 底注 | 门槛 | 需求 |
|---|---|---|
| 1-2 | 300-1600 | 随便什么牌型都能过，重点攒钱和买牌 |
| 3-4 | 2000-10000 | 必须有小丑牌加持，牌型升到 Lv3+ |
| 5-6 | 20000-50000 | **必须有 ×倍率牌**，否则必死 |
| 7-8 | 100000+ | 需要 ×倍率叠加（2-3 张） + 高等级牌型 + 牌组改造 |

## 十、每回合的标准检查清单

1. `mech.py look` 看局面和精确算分
2. 读 Boss 效果 → 判断有无特殊限制
3. 算 `剩余手数 × 最高分` 够不够
4. 不够 → 弃牌（弃满 5 张，留潜力牌）
5. 够了 → 打出最高分组合
6. 每回合结束看商店：
   - 有 ×倍率牌？**优先买**
   - 有星球牌？买来立刻用
   - 消耗品槽满？先用掉
   - 钱 > $25 且没有好牌？考虑 reroll
